# Beginner-CSV-Chatbot.
Beginner-Friendly CSV Chatbot — A simple Python chatbot that searches products in a CSV file. It supports:  Exact keyword search in all columns  Fuzzy matching for misspelled words (e.g., "mikl" → "milk")  Yes/No confirmation for suggestions  Easy-to-update dataset (products.csv)  Built using Python, Pandas, and difflib for beginner-level learning.
