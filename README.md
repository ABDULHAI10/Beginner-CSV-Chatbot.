# 🤖 Beginner CSV Chatbot

**Project Type:** Python / Data Handling / Beginner Project  
**Tools Used:** Python, Pandas, difflib  
**Domain:** Product Search / Chatbot  

---

## 📌 Project Overview
This is a **beginner-friendly Python chatbot** designed to **search products in a CSV file**.  
It demonstrates **basic Python programming, data handling with Pandas, and simple fuzzy matching techniques**.  
The chatbot is easy to customize and serves as a learning project for newcomers in **Python and data processing**.  

---

## 🔍 Features
- ✅ **Exact keyword search** across all columns of the CSV.  
- ✅ **Fuzzy matching** for misspelled words (e.g., `"mikl"` → `"milk"`).  
- ✅ **Yes/No confirmation** for suggested matches.  
- ✅ **Easy-to-update dataset** (`products.csv`) for adding new products.  
- ✅ Built using **Python, Pandas, and difflib** — ideal for beginner learning.  

---

## 🧰 Tools & Technologies
- **Python:** Core programming  
- **Pandas:** CSV handling and data manipulation  
- **difflib:** Simple fuzzy string matching  
- **CSV files:** Lightweight dataset storage
